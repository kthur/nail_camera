# nail_camera

## Overview
This Android app captures nail images, extracts features, and uses a TensorFlow Lite model (combined with a LLM) to provide nail‑health insights.

## New Dataset Integration & Model Retraining
We now support automatic download, preprocessing, and retraining using four public nail‑disease datasets:
1. **DermNet NZ – Nail Images** (~300 images)
2. **ISIC Archive – Nail Images** (~1,200 images)
3. **Roboflow – Nail Disease Detection** (~2,500 images)
4. **Hugging Face – onychomycosis** (~1,000 images)

The workflow adds three scripts under `scripts/` and a training script under `model_training/`.

### Prerequisites
- **Python 3.9+**
- pip packages (install once):
```bash
pip install tensorflow pillow requests python-dotenv huggingface_hub
```
- **Android SDK** and Gradle for building the app.
- (Optional) API keys for ISIC and Roboflow – place them in a `.env` file at the project root:
```
ISIC_API_KEY=your_isic_key
ROBOFLOW_API_KEY=your_roboflow_key
```

### Quick Start with Bash Script
A convenience script `run_all.sh` automates the whole pipeline.
```bash
# Make the script executable (once)
chmod +x run_all.sh

# Run the end‑to‑end pipeline
./run_all.sh
```
The script performs the following steps automatically:
1. Installs required Python dependencies.
2. Downloads the four public nail‑disease datasets.
3. Preprocesses images (resize, augment, generate unified CSV).
4. Trains a MobileNetV2 TFLite model (`model_v2.tflite`).
5. Builds the Android app (debug APK).

If you prefer manual control, the individual commands are:
```bash
# 1. Install dependencies (run once)
python3 -m pip install --upgrade pip
python3 -m pip install tensorflow pillow requests python-dotenv huggingface_hub

# 2. Download datasets
python3 scripts/download_nail_datasets.py --dest datasets

# 3. Preprocess images
python3 scripts/preprocess_nail_data.py --datasets datasets --label_map app/src/main/assets/label_map.json

# 4. Train the model
python3 model_training/train_nail_classifier.py \
    --data_csv datasets/all_nail_data.csv \
    --output_dir app/src/main/assets \
    --model_name model_v2.tflite \
    --epochs 20 \
    --batch_size 32

# 5. Build the Android app (Debug APK)
./gradlew clean assembleDebug  # or `gradle clean assembleDebug`
```

---
### Troubleshooting
- **Missing API keys** – The download script will skip ISIC/Roboflow if no key is provided.
- **GPU not available** – `TFLiteClassifier` falls back to CPU automatically.
- **Out‑of‑memory on training** – Reduce `--batch_size` or train on a machine with more RAM.

### Step‑by‑Step Instructions
1. **Download datasets**
   ```bash
   python scripts/download_nail_datasets.py --dest datasets
   ```
   The script creates `datasets/dermnet`, `datasets/isic`, `datasets/roboflow`, and `datasets/huggingface` with an `images/` subfolder for each.

2. **Preprocess images**
   ```bash
   python scripts/preprocess_nail_data.py --datasets datasets --label_map app/src/main/assets/label_map.json
   ```
   - Images are resized to **150×200** (matching the on‑device extractor).
   - Light augmentations (horizontal flip, brightness jitter) are applied.
   - A `labels.csv` is generated per source and merged into `datasets/all_nail_data.csv`.

3. **Train the TFLite model**
   ```bash
   python model_training/train_nail_classifier.py \
       --data_csv datasets/all_nail_data.csv \
       --output_dir app/src/main/assets \
       --model_name model_v2.tflite \
       --epochs 20 \
       --batch_size 32
   ```
   The script:
   - Loads the merged CSV, finds the processed images, builds a MobileNetV2 classifier.
   - Saves `model_v2.tflite`, `nail_classifier.txt` (label list), and `model_version.txt` (e.g., `v2`).
   - Uses TensorFlow Lite optimization for a small on‑device footprint.

4. **Rebuild the Android app**
   ```bash
   ./gradlew clean assembleDebug
   ```
   The app will automatically pick up `model_v2.tflite` via `ModelVersionProvider`, and inference will run on the GPU delegate if the device supports it.

5. **Run the app**
   Install the generated APK on a device, capture nail images, and view the enhanced health analysis.
